# Word Art

Turn a few words into a title on your Drawdy board. Type up to three lines, pick a style (retro 3D, neon, chrome, outline, bubble or rainbow wave), a font, two colours, an arc and a size, and place it as a transparent image. Select it later to change the words or the style and update it in place.

Building it yourself? See [DEVELOPMENT.md](DEVELOPMENT.md).
